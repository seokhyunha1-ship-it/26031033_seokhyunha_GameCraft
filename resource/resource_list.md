### 경로와 연결

아래 경로는 프로젝트 저장소 루트 기준이다. 개별 파일명은 각 표의 폴더 아래에 있다.

| 항목 | 경로 / 연결 |
|---|---|
| 이미지 원본 | `resource/resource/images/` |
| 음원 원본 | `resource/resource/sounds/` |
| 이미지 조사 기록 | `resource/image-audit.json` (기존 조사 자료) |
| WAV 생성 코드 | `tools/generate_audio.py` |
| 게임 코드 | `src/csharpproject/26031033_seokhyunha_fishjump/26031033_seokhyunha_fishjump/` |
| 실행 시 이미지 | 실행 폴더의 `assets/images/` → ResourceManager.Draw |
| 실행 시 음원 | 실행 폴더의 `assets/sounds/` → AudioManager |

프로젝트 파일이 원본 리소스를 빌드 출력의 `assets/`로 복사한다. 교체할 때는 원본 폴더를 수정하고 다시 빌드한다.

### 이미지 표시 규칙

- 배경은 BackgroundManager.Name이 구간과 최고 높이에 따라 선택하고, Draw에서 전환한다. `배경6.png`는 없으며 첫 우주 배경은 `배경6예시1.png`를 사용한다.
- 헤엄은 1→2→3 순서, 패링은 01→05 순서다. 물·첨벙 파일의 1~6은 애니메이션 순번이 아니라 배경 구간 번호다.
- `래피.png`, `블피.png`는 세로 또는 대각선 헤엄에 사용한다. 미사용 이미지가 아니다.
- 새 오리1/2/3은 3(닫힘)→2(중간)→1(펼침)→2→3으로 입과 날개 동작을 잇는다. 오리 전체 그림을 화면 폭의 1.9배로 그려, 펼친 입이 하단 양옆을 약6%씩 넘는다. 입 중심을 화면 중앙에 맞추고 몸통은 화면 아래로 이어진다. 상단 노출 높이는400세계단위이며 탈락선은 화면 바닥이다. 공격 시에는 펼친 입으로 불을 내뿜는다.
- 사용 중은 현재 코드에서 선택·표시하는 항목을 뜻한다. 로딩 검사에서 읽었다는 이유만으로 사용 중으로 분류하지 않는다.

아이템은 매 판 공중 선택 확률30~70%를 뽑고 개별 배치를 추첨한다. 실제 개수 비율은 고정하지 않는다. 안전한 공중 공간이 없으면 물 안으로 옮긴다. 건사료 회복24, 일반 점프 상한75, 팔딱 비용은 해당 점프 실제 지불량의25%이며 UI도 같은 값을 사용한다.

### 로딩과 메모리

- 원본 PNG는 보존하고 로딩 시 긴 변을 배경/타이틀1536, 오리2048, 물 플랫폼640, 나머지256픽셀로 제한한다.
- 게임용 스프라이트를 시작 시 미리 읽고, 최근 사용 순서로 캐시를 유지한다. 픽셀 저장량96MiB·96개 한도이며 디코더 임시 메모리·드라이버 메모리는 별도다.
- 원본을 교체한 경우 기존 파일명과 실제 코드 연결을 함께 점검한다. `image-audit.json`은 과거 조사 자료이므로 최신 목록의 기준으로 그대로 재사용하지 않는다.

## 7. 오늘 변경된 리소스와 확인 결과

| 변경 | 내용 |
|---|---|
| 오리 교체 | 사용자가 이전 오리입1/2/3을 오리1/2/3으로 교체. 현재 원본에 이전3개는 없음 |
| 효과음 교체 | sfx_parry.wav를 금속성 타격+상승 잔향0.36초로 갱신 |
| 효과음 추가 | sfx_bite.wav, 저음 충격+딱 소리0.22초. 기존 hit는 불 피격용 유지 |
| 그림 재사용 | 파란물1첨벙이펙트를 수둔 명중 물보라, 래피/블피 기본 자세를 탈락 잔상에 사용 |
| 표시 개선 | 불·아이템·수둔·패링 크기 확대 및 코드 효과 추가. 해당 PNG 원본은 변경하지 않음 |
| 생성 도구 | 기존 tools/generate_audio.py에 --only 지원. 두 소리만 갱신하려면 --only sfx_parry sfx_bite |

원본 폴더의128개 파일을 목록의 개별 행과 대조했다. PNG99개 해상도/알파와 WAV19개 길이/형식을 재확인했다. MP3 10개는 선택형 보관 음원이며 출처 미확인 상태를 임의로 변경하지 않았다. 이번 문서 정리는 게임 코드·원본 리소스·실행 파일을 변경하지 않는다.
