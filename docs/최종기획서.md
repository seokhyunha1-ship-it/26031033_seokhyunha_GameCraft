# Jumping Fish 통합 기획서

작성자: 하석현 / 구현 정리: Codex / 2026-10-25
원본 `기획서.md`는 보존한다. 본 문서는 최신 실행 지시를 반영한 구현 기준이다.

## 목표와 시작

2인 로컬 협력 종스크롤 게임. 래피와 블피가 물 플랫폼을 따라 상승하고 거대 오리의 입을 피한다. 클리어는 없으며 둘 모두 잡히면 종료된다. 한 명이 잡혀도 다른 플레이어는 계속 진행한다. 탈락자의 최고 높이는 유지한다.

최신 변경에 따라 땅 출발과 복잡한 오리 습격 연출은 사용하지 않는다. 타이틀 입력 → 1.5초 준비 → 물에서 시작한다. 오리는 아래에서 계속 올라온다. 사망 전용 이미지를 추가하지 않으며 입 경계에 도달한 물고기는 사라진다.

## 조작 및 상태

원본에서 실제 키 배정은 미정이었다. 충돌을 피하기 위해 다음 초기값을 채택했고 `game-settings.json`에서 변경할 수 있다.

| 동작 | 래피 | 블피 |
|---|---|---|
| 상하좌우 헤엄 / 공중 조작 | W S A D | ↑ ↓ ← → |
| 점프 충전 / 패링 | Space | Enter |
| 메뉴 | ESC | ESC |

Title은 아무 키/마우스 버튼 입력을 받는다. 준비 중 입력은 플레이 전환 때 초기화한다. 메뉴는 ↑↓ 선택, Enter 실행, ESC 복귀. Pause는 Resume/Restart/Results/Quit, GameOver는 Restart/Results/Title/Quit를 제공한다. Results는 실제 높이·공격·보너스를 표시한다.

## 점프와 입력 우선순위

- 1m=10px, 게이지 초기값·상한100, 충전50포인트/초.
- 누른 다음 입력 갱신의 방향을 저장하고, 떼는 순간 게이지를 차감하고 발사한다.
- 소비량은 최소1, 최대100, 현재 게이지 이하. 1미만이면 일반 점프 불가.
- 1포인트당 기준거리0.5m. 수직 점프 초기속도는 `sqrt(2 × 중력 × 기준거리px)`로 계산한다. 공중 중력·조작 때문에 다른 방향의 실제 이동궤적은 달라진다.
- 여러 방향 입력은 합성하지 않고 그중 하나를 같은 확률로 선택한다. 무입력 발사 방향은 위.
- 물속에서 누르면 충전과 0.20초 패링 창을 함께 연다. 패링 성공은 충전을 취소하고 무료 도약한다. 성공 이후 키를 떼어도 일반 점프를 추가 발동하지 않는다. 공중에서는 패링 창만 연다.
- 일반 불은 패링할 수 없다. 같은 불은 소비 표시 후 제거되어 중복 피격되지 않는다.

## 물·이동·협력

물은 모든 방향에서 진입 가능하다. 자신 색에서는 실제 헤엄 이동에 비례해 게이지를 회복하며 반대 색에서는 감소한다. 반대 색에는 회복을 중첩하지 않는 초기 해석을 채택했다. 게이지0에서도 헤엄 가능하지만 부력은0이다. 헤엄을 멈추면 헤엄 지속시간에 따른 재입력 지연이 생긴다.

기본 중력260px/s², 부력210px/s², 헤엄95px/s, 회복6포인트/m, 반대색 감소14포인트/s. 부력은 헤엄 상태에서 작용하고 발사 직후 도약 중에는 적용하지 않아 기준 점프 높이를 유지한다.

점프로 **다른** 플랫폼에 들어갈 때 래피는 파랑→빨강, 블피는 빨강→파랑으로 바꾼다. 출발 플랫폼 재진입·단순 머무르기는 변경하지 않는다. 동일 시점 접촉은 직전 색을 함께 읽는다. 같은 물리 틱 안에서도 진입 비율을 계산해 순차 접촉은 시간순으로 반영한다.

## 오리·전투·아이템

오리 상승속도 초기13px/s. 4초마다 수직 위 기준 -60°~+60° 범위에20° 간격으로7발(기본색6, 반대색 특수1)을180px/s로 발사한다. 화면에서 특수 불은 + 표시로 구별한다. 피격은 게이지20 감소.

패링 거리30px, 유효시간0.20초. 래피는 파란 특수 불, 블피는 빨간 특수 불만 성공한다. 성공은 공격데미지20, 현재 게이지×0.4 상당의 무료 점프. 잘못된 특수 불은20 감소 한 번. 시간 경과 후 가까이 부딪히면 일반 피격이다.

수둔은 획득 즉시 아래로420px/s 발사한다. 공격력은 획득 당시 게이지×설정계수(초기1). 발사 시점에는 점수가 오르지 않고 실제 오리 높이와 충돌할 때 누적한다. 캐릭터별 시전·투사체 이미지를 사용한다. 건사료는30 회복, 상한100. 플랫폼별 아이템 생성확률0.65, 그중 수둔0.4, 나머지 건사료. 설정에서 조절한다.

## 생성·카메라·배경

세계 좌표의 위쪽이+Y, 출발 높이0. 화면 좌표는 카메라를 빼서 변환한다. 카메라는 상향으로만 진행하며 최고로 살아 있는 물고기를 따라가고 오리 상승도 하한으로 반영한다.

플랫폼 폭은 소형130~210px, 중형250~360px, 대형430~570px이며 두께도55~105px로 달라진다. 중심 간 세로110~150px, 이전 플랫폼과 최소60px 수평 겹침을 유지한다. 좌향 계단·우향 계단·지그재그·흩어진 배치를 섞고, 색상도 교대·두 개씩 묶음·무작위로 변화한다. 30포인트 기준거리150px보다 좁은 간격으로 기하학적으로 도달 가능한 경로를 만든다. 잔여 게이지·실제 조작 실패까지 무조건 구제하는 규칙은 아니다. 시작 물 폭960px. 화면 위1000px까지 생성하고 카메라 아래650px는 정리한다. `Seed`가 null이면 새 맵, 정수면 동일 생성열. 맵·공격·입력 난수를 분리했다.

| 구간 | 시작 높이(px / m) | 배경 |
|---|---|---|
| 1 | 0 / 0 | 배경1 |
| 2 | 300 / 30 | 배경2 |
| 3 | 700 / 70 | 배경3 후 예시1~3 반복, 끝200px 예시3 |
| 4 | 2200 / 220 | 배경4 후 예시1~3, 끝300px 4→5 전환 |
| 5 | 4000 / 400 | 배경5 후 예시1~3, 끝300px 5→6 전환 |
| 6 | 6000 / 600 | 예시1, 예시2·3 반복, 구간 진입2500px 후 예시4 |

구간 시작150px는 기본 배경, 변형은500px 간격을 기준으로 순환한다. `배경6.png`는 실제 파일이 없어 예시1로 대체한다. 이미지 종횡비 유지, 확대 채우기, 약1.67초 혼합 전환과 약한 수직 이동을 적용한다. 색상·질감 원본은 그대로 둔다. 별·구름은 제공 배경에 포함된 상태이며 별도의 랜덤 입자 시스템은 이번 통합 빌드에 추가하지 않았다.

## 점수·저장

`(래피 최고높이m + 블피 최고높이m) ×10 + 누적 실제데미지×5 + 구간 최초 보너스`

구간2~6 최초 보너스100/200/300/400/500. 최고 높이 기준으로 지급하며 카메라나 예시 이미지 변경은 보너스를 발생시키지 않는다. 최고 기록은 `%LOCALAPPDATA%/JumpingFish/record.txt`에 게임 오버 때 저장한다. 파일 저장 실패는 runtime.log에 남긴다.

## 그림·사운드·조정 사항

기존99 PNG를 로드하고 알파를 보존했다. 기본 캐릭터2장은 원본 보존용이며 동작 프레임을 실제 플레이에 사용한다. 10 제공 MP3는 출처 확인 전 기본 비활성화. 직접 만든 효과음13개·BGM4개를 기본 사용한다. 음량 설정은 독립적이며 BGM은 루프·점진 전환한다. Pause 중 게임과 오디오 진행을 멈춘다.

확정 수치(점프 환산, 충전, 패링, 불7발/4초, 점수식)는 유지했다. 중력·회복·맵 간격·키·배경 높이·아이템 확률·음량은 초기 조정값이다. 실제 2인 장시간 난이도 조율과 키보드 동시입력 한계는 추가 플레이 평가 대상이다.


### 물 플랫폼 분포 확대 (2026-10-25)
높이 구간마다 2~3개를 생성한다. 기존 점프 경로의 폭과 60px 이상 수평 겹침을 유지하고, 남는 좌우 공간을 나누어 작은/중간 플랫폼을 추가한다. 추가 플랫폼은 높이를 ±5px 달리하며 최소 24px 수평 간격을 둔다. 추가 경로의 아이템 생성 확률은 기본의 25%다. 200개 시드에서 좌·중앙·우 분포, 개수, 화면 경계와 비겹침을 확인했으며 전체 자동 검증 32/32, Release 빌드 오류·경고 0개. 최신 실행본은 bin/PlatformDensity.


### 메뉴 클릭 및 공중 물 접촉 규칙 (2026-10-25)
일시정지/게임오버 메뉴와 기록 돌아가기를 마우스로 선택 가능. 창 여백을 제외한 게임 좌표로 클릭 판정. 공중에서 자기 색 물 접촉 시 삐삐 경고음과 함께 플랫폼 아래로 밀려나며 추락 상태가 된다. 같은 색에 다시 닿아도 거부된다. 반대 색 물에 접촉해야 자기 색으로 바꾸며 입수하고 추락 제한이 해제된다. 래피와 블피에 대칭 적용하며 시작 물에서의 헤엄은 유지한다. 최신 실행본: bin/WaterRules.
