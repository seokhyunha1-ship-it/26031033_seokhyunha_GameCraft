기말과제 게임 기획서
jumping fish

작성자 : 하석현
문서 상태 : 1차 기획 초안

※ 사용자가 정한 규칙과 작성을 위임한 초기 수치를 반영하였다.
※ '초기 설정값'은 실제 플레이 테스트를 통해 조정할 수 있다.
※ 추가 해석이 필요한 부분은 마지막 항목에 따로 명시하였다.

==================================================
1. 게임 개요
==================================================

- 타이틀 : jumping fish
- 장르 : 종스크롤 2D 플랫포머
- 핵심 요소 : 협력, 헤엄, 점프, 추격 회피, 패링, 기록 경쟁
- 등장 캐릭터 : 래피, 블피
- 플레이 인원 및 캐릭터별 개별 키 배정 : 미정

[게임 소개]
래피와 블피가 자신들을 잡아먹으려는 거대한 오리를 피해,
물 플랫폼 안에서 헤엄치고 플랫폼 사이를 점프하며 올라가는 게임이다.

플랫폼의 색깔과 점프 게이지를 관리하고, 서로 이동 타이밍을 맞춘다.
아이템과 패링으로 오리를 공격하며, 두 캐릭터가 각각 도달한
최고 높이와 오리에게 준 데미지를 점수로 환산한다.

클리어 조건은 없으며, 두 캐릭터가 모두 잡아먹힐 때까지
최대한 높은 점수를 기록하는 것이 목표이다.

==================================================
2. 게임 스토리
==================================================

래피와 블피는 평화롭게 살아가던 중, 자신들을 잡아먹으려는
거대한 오리를 만나 도망치기 시작한다.

정신없이 도망가던 둘은 그만 뭍에 도달하고 만다.
오리에게 잡아먹히려는 위기의 순간, 신비한 물결이 두 물고기를
감싸며 도망갈 길로 인도한다.

래피와 블피는 그 물결을 따라 도망가지만, 오리는 추격을 멈추지 않는다.
두 물고기는 서로 협력하여 물 플랫폼을 타고 위로 올라가야 한다.

"오리에게 잡아먹히지 말고 도망가라."

==================================================
3. 게임 목적 및 재미 요소
==================================================

[게임 목적]
- 오리에게 잡아먹히지 않도록 계속 위로 올라간다.
- 두 캐릭터 각각의 최고 도달 높이를 높인다.
- 헤엄과 점프를 연결하여 점프 게이지를 관리한다.
- 아이템과 패링으로 오리에게 데미지를 주어 추가 점수를 얻는다.
- 상승 점수와 공격 점수의 합으로 높은 기록을 달성한다.

[재미 요소]
- 협력 : 플랫폼에 진입하는 순서와 점프 타이밍을 맞추는 재미
- 색깔 변화 : 동료의 진입으로 바뀐 플랫폼 상태에 대응하는 판단
- 이동 : 물속에서 헤엄치다가 다른 플랫폼으로 도약하는 재미
- 자원 관리 : 점프에 필요한 게이지를 회복하고 나누어 사용하는 판단
- 긴장감 : 아래에서 계속 올라오는 오리를 피해 이동하는 압박
- 패링 : 불 색깔에 맞는 캐릭터로 정확한 순간에 대응하는 재미
- 연계 이동 : 게이지 소모 없는 패링 후 점프로 이동을 이어 가는 재미
- 기록 경쟁 : 최고 높이와 공격 점수를 함께 높여 기록을 갱신하는 재미

==================================================
4. 캐릭터 및 조작
==================================================

[래피]
- 파란색 물 플랫폼에 점프로 진입하면 해당 플랫폼을 빨간색으로 바꾼다.
- 빨간색 물 플랫폼에 접촉하면 색깔을 바꾸지 않는다.
- 파란색 물 플랫폼에서 헤엄치면 점프 게이지가 서서히 감소한다.
- 파란색 패링 대상 불만 패링할 수 있다.

[블피]
- 빨간색 물 플랫폼에 점프로 진입하면 해당 플랫폼을 파란색으로 바꾼다.
- 파란색 물 플랫폼에 접촉하면 색깔을 바꾸지 않는다.
- 빨간색 물 플랫폼에서 헤엄치면 점프 게이지가 서서히 감소한다.
- 빨간색 패링 대상 불만 패링할 수 있다.

[공통 조작]
- 시작 화면에서 아무 버튼 : 땅에서 출발 준비 상태로 진입
- 방향키 : 물속 헤엄 / 점프 방향 지정 / 공중 방향 조작
- Space 누르기 : 일반 점프 충전 시작
- Space 떼기 : 일반 점프 발동
- 패링 가능한 대상 근처에서 타이밍에 맞춘 Space 입력 : 패링
- ESC : 메뉴 열기
- 메뉴의 재시작 : 처음부터 다시 시작
- 메뉴의 종료 : 게임 종료

[여러 방향키 동시 입력]
- 동시에 입력된 방향 중 한 방향을 무작위로 선택한다.
- 예 : 위 + 오른쪽을 동시에 입력하면 위 또는 오른쪽 중 하나를 선택한다.
- 두 방향을 합쳐 대각선 방향으로 처리하지 않는다.
- 초기 구현안 : 각 동시 입력 방향의 선택 확률은 동일하게 한다.

※ 위 키는 공통 동작을 설명하는 기준이다.
   두 캐릭터가 독립적으로 조작할 실제 키 배정은 추가로 정한다.

==================================================
5. 물 플랫폼 규칙
==================================================

[기본 성질]
- 물 플랫폼은 빨간색과 파란색의 두 종류이다.
- 물 플랫폼은 위·아래·좌·우 어떤 방향에서도 들어갈 수 있다.
- 내부에서 헤엄칠 수 있으며 부력이 작용한다.
- 부력은 중력보다 약하므로 헤엄치지 않으면 결국 아래로 떨어진다.
- 점프 게이지가 0이면 부력은 적용되지 않는다.

[색깔 변경 시점]
- 점프로 다른 물 플랫폼에 닿는 순간 색깔 변경을 판정한다.
- 래피가 파란색 플랫폼에 진입 : 빨간색으로 변경
- 블피가 빨간색 플랫폼에 진입 : 파란색으로 변경
- 래피가 빨간색 플랫폼에 접촉 : 변화 없음
- 블피가 파란색 플랫폼에 접촉 : 변화 없음
- 패링 후 점프로 다른 물 플랫폼에 진입해도 동일하게 적용한다.
- '변화 없음'은 색깔 변경이 없다는 뜻이다.
  물속 이동과 부력 등 공통 규칙은 그대로 적용한다.

[두 캐릭터의 동시 접촉]
- 접촉 직전의 플랫폼 색깔을 기준으로 두 캐릭터를 함께 판정한다.
- 한 캐릭터의 색깔 변경 결과를 같은 순간의 다른 접촉에 다시 적용하지 않는다.

예시 1 : 원래 빨간색인 플랫폼에 래피와 블피가 동시에 접촉
         -> 래피는 원래 빨간색이므로 변경 없음
         -> 블피는 원래 빨간색을 파란색으로 변경
         -> 최종 색깔 : 파란색

예시 2 : 원래 파란색인 플랫폼에 래피와 블피가 동시에 접촉
         -> 래피는 원래 파란색을 빨간색으로 변경
         -> 블피는 원래 파란색이므로 변경 없음
         -> 최종 색깔 : 빨간색

[접촉 시점에 차이가 있는 경우]
- 실제 접촉 순서대로 변경된 색깔을 기준으로 다음 접촉을 판정한다.
- 빨간색 플랫폼에 블피가 먼저 접촉하면 파란색이 된다.
- 그 직후 래피가 늦게 접촉하면 파란색이 다시 빨간색이 된다.
- 같은 플랫폼에 머무는 것만으로 색깔 변경을 반복하지 않는다.

[게이지 감소 상황 예시]
- 래피가 빨간색 플랫폼 안에 머무는 동안 블피가 진입하면 파란색이 된다.
- 이후 래피가 그 플랫폼에서 헤엄치면 반대 색에 의한 게이지 감소가 적용된다.
- 블피도 래피의 진입으로 플랫폼이 빨간색이 되면 같은 원리로 영향을 받는다.

==================================================
6. 헤엄 및 점프 게이지 규칙
==================================================

[게이지 표시]
- 초기 게이지 : 캐릭터별 100%
- 수치 계산 기준 : 100%를 100포인트로 표기
- '20포인트 감소'는 현재 게이지의 20%가 아닌 게이지 수치 20 감소이다.
- 게이지는 0 미만으로 내려가지 않는다.

[헤엄]
- 방향키를 누르는 시간이 길수록 헤엄치는 거리가 길어진다.
- 한 번 헤엄친 뒤 다음 헤엄까지 딜레이가 발생한다.
- 멀리 헤엄칠수록 다음 헤엄까지의 딜레이가 길어진다.
- 딜레이 중에는 다음 헤엄을 즉시 실행할 수 없다.

[회복과 감소]
- 물 플랫폼 안에서 헤엄친 거리에 비례하여 게이지가 찬다.
- 래피는 파란색, 블피는 빨간색 플랫폼에서 헤엄치면 게이지가 서서히 감소한다.
- 건사료를 획득하면 게이지를 일정 수치 회복한다.
- 일반 점프와 불 피격은 게이지를 소모하거나 감소시킨다.
- 패링 후 점프는 게이지를 소모하지 않는다.

[게이지 0]
- 물 플랫폼의 부력이 중단된다.
- 중력에 의해 아래로 떨어진다.
- 게이지 0 자체가 즉시 게임 오버를 의미하지는 않는다.

※ 헤엄 회복과 반대 색 감소의 중첩 방식, 회복률·감소율,
   게이지 상한 및 게이지 0에서의 헤엄 가능 여부는 추가 결정 사항이다.

==================================================
7. 일반 점프 규칙
==================================================

[입력과 발동]
- Space를 누르면 충전을 시작한다.
- Space를 누른 시간에 비례하여 사용할 게이지가 증가한다.
- Space를 떼는 순간 점프를 발동한다.
- 사용한 게이지가 많을수록 점프 거리가 비례하여 증가한다.

[방향]
- 점프키를 입력한 다음 시점에 입력하고 있는 방향키 방향을 사용한다.
- 초기 구현 해석 : Space를 누른 다음 입력 갱신 시점의 방향을
  발사 방향으로 저장하고, Space를 떼면 저장한 방향으로 점프한다.
- 여러 방향키가 입력되어 있으면 그중 한 방향을 무작위로 선택한다.
- 공중에서도 방향키를 이용하여 방향을 조작할 수 있다.

[초기 설정값]
- 충전 속도 : 초당 게이지 50포인트
- 점프 거리 계수 : 게이지 1포인트당 0.5m
- 계산 기준 : 게임 공간 1m = 10px
- 일반 점프 최소 소비량 : 1포인트
- 일반 점프 1회 최대 소비량 : 100포인트
- 보유 게이지보다 많이 사용할 수 없다.
- 게이지가 1포인트 미만이면 일반 점프를 발동하지 않는다.

[계산식]
- 예정 소비량 = Space를 누른 시간(초) × 50
- 실제 소비량 = 예정 소비량을 최소 1, 최대 100으로 제한한 뒤
                보유 게이지를 초과하지 않도록 제한한 값
- 점프 기준 거리 = 실제 소비량 × 0.5m
- 초기 구현안 : 실제 게이지 차감은 Space를 떼어 발동할 때 적용한다.
  충전 중에는 현재 게이지와 예정 소비량을 구분하여 표시한다.

[거리 예시]
- 1포인트 사용 : 0.5m
- 20포인트 사용 : 10m
- 50포인트 사용 : 25m
- 100포인트 사용 : 50m
- 100포인트 보유 시 최소 기준 거리 0.5m, 최대 기준 거리 50m
- 40포인트만 보유했다면 최대 기준 거리는 20m

※ 위 거리는 장애물 충돌이나 공중 조작이 없는 상태의 점프 기준값이다.
   실제 도달 위치는 중력, 진입 플랫폼, 공중 조작에 따라 달라질 수 있다.
※ 일반 점프의 방향키 미입력 시 방향과 공중 조작 강도는 미정이다.

==================================================
8. 오리의 추격 및 불 공격
==================================================

[추격]
- 오리는 일정한 속도로 위로 올라오며 입을 접었다 펴는 동작을 반복한다.
- 오리의 상승에 따라 화면이 위로 스크롤된다.
- 한 화면이 위로 스크롤되는 동안 충분히 올라가지 못한 캐릭터는
  오리에게 잡아먹힌다.
- 한 캐릭터가 잡아먹혀도 다른 캐릭터가 살아 있으면 계속 진행한다.
- 두 캐릭터가 모두 잡아먹히면 게임 오버이다.

[불 발사 : 초기 설정값]
- 공격 쿨타임 : 4초
- 1회 발사량 : 총 7개
- 구성 : 기본 색 불 6개 + 반대 색 패링 대상 불 1개
- 기본 색 : 빨간색 또는 파란색을 각각 50% 확률로 선택
- 발사 위치 : 오리 입 중앙
- 발사 방향 : 위쪽을 중심으로 부채꼴 7방향
- 방향 각도 : 수직 위 기준 -60, -40, -20, 0, +20, +40, +60도
- 반대 색 불 : 7개 방향 중 한 곳을 매 공격마다 무작위 선택
- 발사 속도 제안 : 초당 18m
- 불 크기 제안 : 반지름 0.6m인 원
- 첫 공격은 추격 시작 후 4초가 지났을 때 실행한다.

예시 : 기본 색이 빨간색이면 빨간색 불 6개와 파란색 불 1개를 쏜다.
       파란색 불 1개는 래피가 패링할 수 있다.

[불 피격]
- 피격 순간 해당 캐릭터의 점프 게이지가 일정 수치 감소한다.
- 초기 감소량 : 20포인트
- 남은 게이지가 20 미만이면 0으로 처리한다.
- 초기 충돌 처리안 : 피격 처리한 불은 소멸하여 같은 불의 중복 피격을 막는다.
- 게이지가 0이 되면 부력이 중단되어 낙하한다.

9. 패링 규칙
==================================================

[대상과 캐릭터]
- 한 공격에서 기본 색과 다른 색으로 발사된 불 1개만 패링 대상이다.
- 빨간색 패링 대상 불 : 블피만 가능
- 파란색 패링 대상 불 : 래피만 가능
- 기본 색 불 6개는 캐릭터와 색 조건이 맞더라도 패링 대상이 아니다.

[성공 조건 : 초기 설정값]
- 캐릭터 중심과 대상 불 중심의 거리 : 3m 이내
- Space를 누른 순간부터 0.20초 동안 패링 판정을 활성화한다.
- 이 시간 안에 해당 캐릭터가 패링 가능한 불이 범위에 들어오면 성공한다.
- 이미 범위 안에 있다면 Space를 누른 순간 성공 여부를 판정한다.
- 성공한 불은 처리 완료하여 같은 불로 반복 패링하거나 피격되지 않게 한다.

[성공 효과]
- 오리에게 데미지를 준다.
- 패링 데미지는 불 1회 피격의 기준 수치와 동일하게 20으로 설정한다.
- 플레이어 피격은 게이지 20포인트 감소,
  패링 공격은 오리에게 데미지 20으로 서로 다른 대상에 적용한다.
- 패링 성공에 따른 오리 데미지는 공격 점수에 반영한다.
- 패링 성공 위치에서 패링 후 점프를 할 수 있다.

[실패 결과]
- 패링에 실패하면 불에 피격된 것과 동일하게 게이지 20포인트를 잃는다.
- 초기 처리안 : 패링 대상이 범위에 있어 시도한 경우를 패링 시도로 보며,
  잘못된 캐릭터로 시도하거나 성공 시간을 놓치면 실패 처리한다.
- 단순한 일반 점프나 주변에 대상이 없는 Space 입력은 패링 실패가 아니다.
- 같은 불에 대한 패링 실패와 피격을 중복 적용하지 않는다.

[패링 후 점프 거리]
- 성공 시 보유한 현재 게이지의 약 40%를 일반 점프에 사용했을 때의 거리이다.
- 초기 계산은 40%를 사용한다.
- 패링 후 점프 거리 = 현재 게이지 × 0.4 × 0.5m
- 실제 게이지는 소모하지 않는다.
- 일반 점프의 최소 소비량 1포인트 제한을 패링 후 점프에는 적용하지 않는다.

예시 : 현재 게이지 80
       -> 일반 점프에 32포인트를 사용하는 거리인 16m
       -> 패링 후 점프 자체는 게이지를 차감하지 않으므로 80 유지

[패링 후 점프 방향]
- 방향키 입력 중 : 입력한 방향으로 이동
- 여러 방향키 입력 중 : 입력된 방향 중 하나를 무작위 선택
- 방향키 미입력 : 기존에 점프하던 방향 유지
- 기존 점프 방향이 없음 : 위쪽으로 이동
- 공중 방향 조작이 가능하다.
- 도착한 다른 물 플랫폼의 색깔 변경은 일반 점프와 동일하게 처리한다.

※ 패링 성공 후 점프의 자동 발동 또는 추가 입력 여부는 아직 미정이다.
※ Space의 일반 점프 충전과 패링 판정이 겹칠 때의 우선순위는
   구현 전에 확정한다.

10. 아이템 규칙
==================================================

[공통]
- 아이템은 물 플랫폼 안이나 점프 이동 경로에 배치한다.
- 획득하면 즉시 자동 발동한다.
- 별도의 사용 키는 필요하지 않다.

[수둔]
- 획득 즉시 아래쪽의 오리를 향해 수둔을 발사한다.
- 획득 순간 보유한 점프 게이지에 비례하여 데미지가 증가한다.
- 오리에게 실제로 준 데미지를 공격 점수로 환산한다.
- 데미지 계수와 수둔 발동 시 게이지 소모 여부는 미정이다.

[건사료]
- 획득하면 점프 게이지를 일정 수치 회복한다.
- 회복량과 생성 빈도는 미정이다.

11. 점수 및 기록 규칙
==================================================

[상승 거리]
- 출발한 땅의 높이를 0m로 정한다.
- 래피와 블피 각각의 최고 도달 높이를 기록한다.
- 합산 상승 거리 = 래피 최고 높이 + 블피 최고 높이
- 아래로 떨어지거나 이미 도달한 높이로 다시 올라와도 중복 가산하지 않는다.
- 잡아먹힌 캐릭터의 최고 높이는 그 시점의 기록으로 유지한다.
- 살아남은 캐릭터는 계속 자신의 최고 높이를 갱신할 수 있다.

[초기 점수 환산 비율]
- 상승 거리 1m당 10점
- 오리에게 준 데미지 1당 5점

[계산식]
- 상승 점수 = (래피 최고 높이 + 블피 최고 높이) × 10
- 공격 점수 = 두 캐릭터가 오리에게 준 누적 데미지 × 5
- 최종 점수 = 상승 점수 + 공격 점수
- 초기 표시안 : 소수값은 내부에서 유지하고 최종 표시 점수의 소수점은 버린다.

[예시]
- 래피 최고 높이 120m, 블피 최고 높이 100m
- 오리에게 준 누적 데미지 60
- 상승 점수 : (120 + 100) × 10 = 2,200점
- 공격 점수 : 60 × 5 = 300점
- 최종 점수 : 2,500점
- 패링 1회 성공 : 데미지 20 × 5 = 공격 점수 100점

[기록 경쟁]
- 별도의 클리어 조건은 없다.
- 두 캐릭터가 모두 잡아먹힌 시점에 최종 점수를 확정한다.
- 오리 공격은 점수 획득 요소이며, 오리 처치에 의한 클리어는 없다.
- 기록의 영구 저장 방식은 추가로 정한다.

12. 시작, 진행, 종료 및 메뉴
==================================================

[시작 화면]
- 게임 제목과 'PRESS ANY BUTTON'을 표시한다.
- 아무 버튼을 누르면 출발 준비 상태로 진입한다.

[출발 준비]
- 시작 플랫폼은 물이 아닌 땅이다.
- 두 캐릭터는 땅에서 각자 게이지 100%로 출발한다.
- 점프하여 첫 물 플랫폼에 들어가면 오리가 올라오는 애니메이션을 연출한다.
- 그 연출을 거쳐 오리의 추격과 종스크롤 플레이를 시작한다.
- 시작 트리거의 초기 해석 : 둘 중 한 캐릭터가 처음 물 플랫폼에
  진입하면 연출을 한 번 실행한다. 두 캐릭터 동시 진입은 필수로 두지 않는다.

[오리 최초 위치 : 초기 설정값]
- 최초 입 상단 높이 : 출발한 땅보다 20m 아래
- 등장 연출 종료 시 입 상단 높이 제안 : 출발한 땅보다 10m 아래
- 등장 연출에서는 입을 움직이며 위로 올라오는 모습을 보여 준다.
- 등장 연출 종료 후 일정 속도 추격과 공격 쿨타임을 시작한다.
- 실제 등장 속도와 추격 속도는 추후 조정한다.

[캐릭터 탈락과 게임 오버]
- 올라가지 못해 오리에게 잡아먹힌 캐릭터는 탈락한다.
- 한 캐릭터만 탈락하면 게임을 계속 진행한다.
- 두 캐릭터가 모두 잡아먹혔을 때만 게임 오버가 된다.
- 게임 오버 시 최종 점수와 두 캐릭터의 최고 높이를 표시한다.

[ESC 메뉴]
- ESC를 누르면 메뉴를 연다.
- 메뉴에서 재시작 또는 종료를 선택할 수 있다.
- 초기 메뉴 구성안 : 계속하기 / 재시작 / 종료
- 초기 동작안 : 메뉴가 열린 동안 추격·공격·이동을 일시정지한다.
- 재시작 시 점수와 최고 높이를 0으로, 두 캐릭터 게이지를 100%로
  초기화하고 땅의 출발 준비 상태로 돌아간다.
- 종료 선택 시 게임을 종료한다.

15. 게임 진행 흐름
==================================================

  -> PRESS ANY BUTTON
  -> 아무 버튼 입력
  -> 땅에서 두 캐릭터 출발 준비, 게이지 각 100%

  -> 오리 등장 애니메이션

  -> 점프 충전 및 발동

  -> 헤엄과 점프 반복

[병행 처리]

  -> 현재 게이지의 40%에 해당하는 거리로 추가 점프 가능
  -> 실제 게이지 소모 없음
  -> 방향키 입력 방향 / 미입력 시 기존 점프 방향 / 기존 방향 없으면 위
- 게이지 0 : 부력 중단 및 낙하
- 한 캐릭터가 잡아먹힘 : 다른 캐릭터는 계속 플레이
- 두 캐릭터 모두 잡아먹힘 : 게임 오버 및 최종 점수 확정
- ESC : 메뉴에서 계속하기·재시작·종료

17. 남은 결정 사항 및 구현 해석 확인

[아직 정하지 않은 규칙]

- 패링 성공 후 점프의 자동 발동 여부와 일반 점프·패링 입력 우선순위
- 수둔 데미지 계수와 게이지 소모 여부, 건사료 회복량
- 점프 이외의 물 플랫폼 진입 시 색깔 변경 여부
- 오리 추격 속도, 입 접촉 및 화면 하단 이탈의 정확한 잡아먹힘 판정
- 무한 플랫폼 공급, 간격, 아이템 배치, 콘텐츠 확장 방식
- 화면 해상도, 리소스, 최고 기록의 영구 저장 방식

[이번 초안의 구현 해석]
- 일반 점프 방향은 Space를 누른 다음 입력 갱신 시점에 저장한다.
- 일반 점프 게이지는 Space를 떼어 발동할 때 차감한다.
- 둘 중 한 캐릭터가 첫 물 플랫폼에 들어가면 오리 등장 연출을 시작한다.
- 패링 실패와 동일 불의 피격은 중복 차감하지 않는다.
- ESC 메뉴 중에는 게임 진행을 일시정지한다.
- 동시 접촉은 동일 시점의 접촉 직전 색깔로 묶어서 판정한다.
  구현 시 단순 처리 순서 때문에 동시 접촉이 순차 접촉으로 바뀌지 않게 한다.
